BEHAVIOUR
- Unlimited enabled backend QR profiles are supported by bank_profiles.
- Every enabled QR receives a 30-minute rotation slot.
- Customer-facing permanent QR remains the same YEEDIPAY /p/CUSTxxxx link QR.
- Each created transaction persists its selected bank_id, locking the route.
- SMS/reconciliation continues matching against the transaction bank_id.

INSTALL
1. Backup files and database.
2. Copy/overwrite patch files into the project root.
3. Import database/qr_rotation_30min_patch.sql.
4. Add/enable QR profiles and run: php tools/qr_pool.php enable-auto
5. Keep using the existing customer permanent QR.
